# E-Book Panduan Pengelolaan Sampah Rumah Tangga
## Desa Panambangan - KKM UMC 2026

### Cara Instalasi:

1. **Install XAMPP**
   - Download dari https://www.apachefriends.org/
   - Install dan jalankan Apache & MySQL

2. **Setup Database**
   - Buka phpMyAdmin (http://localhost/phpmyadmin)
   - Buat database: `e_book_sampah`
   - Import file `database.sql`

3. **Copy File**
   - Copy folder ke `C:\xampp\htdocs\e-book-sampah\`

4. **Akses Aplikasi**
   - Buka browser: http://localhost/e-book-sampah

5. **Login Admin**
   - Username: admin
   - Password: admin123
